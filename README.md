# <img src="https://raw.githubusercontent.com/geekygreek7/animated-pokemon-gifs/master/25.gif" width="45" alt="Pikachu"> Jogo Pokémon

Um jogo inspirado no universo Pokémon. Nele, o jogador deve explorar o mapa em busca de insignias Pokémon e juntar as 4 insignias para vencer!

## 🚀 Tecnologias Utilizadas

- **Frotend:**
  - Html
  - Css
  - JavaScript
  
- **API:**
  -  https://pokeapi.co/
 
## 🕹️ Funcionalidades

- Exploração livre pelo mapa
- Batalhas em 3 arenas
- Recuperação de vida dos pokémons após perder a batalha
- Integração com a PokéAPI para dados reais dos Pokémons
- Escolher um deck de Pokémons para usar nas batalhas

## ⚙️ Como rodar

1. Copiar o repositório
```

git clone https://github.com/Arthurposse/jogo_pokemon.git

```
2. Acessar o diretório
```

cd jogo_pokemon

```
3. Abra a pasta "Tela Home" e clique 2 vezes em cima do arquivo "index.html"
